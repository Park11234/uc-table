UC TABLE 접근성 안내

작성일 2026-10-14 · 앱 버전 1.9.0

UC TABLE은 장애인차별금지법(제21조)과 한국형 웹 콘텐츠 접근성 지침(KWCAG 2.2), 국제 기준 WCAG 2.2 AA를 목표로 만듭니다. 아래는 지금까지 확인한 내용과 남은 한계입니다.

확인한 방법

  • 자동 점검(axe-core, WCAG 2.2 AA 규칙): 밝은·어두운 화면에서 홈·기록·찾아보기·내 정보·증상 기록(모든 단계)·진료용 PDF·설정·시트 화면을 검사해 심각·치명 위반 0건
  • 회귀 점검(Playwright): 화면을 다시 그린 뒤 초점 유지, 시트 안 초점 가두기와 닫은 뒤 초점 복귀, 키보드로 백업 파일 불러오기, 화면 읽기용 알림 영역, 비텍스트 대비 3:1, 터치 영역 44px, 글자 200%와 320px 화면에서 가로 넘침 없음

지원하는 것

  • 키보드만으로 모든 기능 사용(Tab·Enter·Esc), 초점 표시
  • 화면 읽기 프로그램용 이름(레이블)·상태(눌림·현재 화면)·진행 표시
  • 글자 크기: 기기·브라우저 글자 크기 설정과 앱의 '크게·아주 크게'를 따름(rem 단위)
  • 색만으로 뜻을 전하지 않음: 판정은 모양과 글자(좋음·주의·보류·피하기·절대 금지)를 함께 표시
  • 어두운 화면, 동작 줄이기 설정
  • 글자 PDF: 진료용 문서를 글자 그대로 저장해 검색·복사·낭독 가능

알려진 한계

  • 실제 기기의 TalkBack(안드로이드)·VoiceOver(아이폰)로는 아직 확인하지 못했습니다.
  • 설치형 앱은 세로 화면으로 고정되어 있습니다.
  • 증상 점수 그래프는 그림입니다. 같은 내용은 '최근 기록' 목록과 진료용 PDF의 표에 글자로 있습니다.
  • 환자를 모신 사용성 평가는 출시 전에 진행할 예정입니다.
