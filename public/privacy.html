UC TABLE 개인정보 처리방침

시행일 2026-10-17 · 앱 버전 1.11.0부터 적용(이전 방침: 2026-10-14, 1.9.0)

한 줄 요약: UC TABLE은 개인정보를 수집하지 않습니다. 입력한 기록은 사용자의 기기 안에만 저장되고, 개발자를 포함해 누구에게도 전송되지 않습니다. 기록을 기기 밖으로 내보내는 것(백업 파일·공유·진료용 PDF)은 사용자가 직접 할 때만 일어납니다.

1. 처리하는 정보와 저장 위치

앱에 입력하는 증상(배변 횟수·혈변·복통 등), 식사와 먹은 음식, 몸무게, 키·나이·성별, 알레르기, 복용 약, 의료진 지시, 검사 수치·약 메모, 진료 때 물어볼 것, 메모는 사용자의 기기에만 저장됩니다.

  • 기록 본체: 브라우저 저장 공간(localStorage). 안드로이드 앱은 앱 내부 저장 공간
  • 기기 안 자동 보관본: 기록이 바뀐 날마다 하나씩, 최근 7일치를 같은 브라우저의 다른 저장소(IndexedDB)에 둡니다. 기록이 손상되거나 실수로 지웠을 때 되살리는 용도입니다
  • 불러오기 전 기록·손상 사본: 백업을 불러오기 직전의 기록과, 읽지 못한 기록의 사본을 기기 안에 남겨 되돌릴 수 있게 합니다
  • 백업 암호화 열쇠(켰을 때만): 비밀번호에서 만든 열쇠를 꺼낼 수 없는 형태로 기기 안(IndexedDB)에 둡니다. 비밀번호 자체는 저장하지 않습니다
  • 자동 백업 폴더 연결(PC의 크롬·엣지에서 켰을 때만): 고른 폴더에 접근할 수 있는 연결 정보를 기기 안에 둡니다
  • 안드로이드 앱을 1.9.0 이하에서 1.10.0 이상으로 올릴 때 예전 버전의 기록을 옮기려고 앱 내부 파일(migrated-v1.json)에 한 번 복사합니다

앱에는 서버·회원 가입·로그인이 없습니다. 개발자는 이 기록을 볼 수도, 받을 수도 없습니다.

2. 외부로 보내는 정보

없습니다. 분석 도구, 광고, 추적 코드, 사용 통계를 쓰지 않습니다. 앱이 쓰는 글꼴과 라이브러리도 앱 안에 들어 있어 외부 서버에서 받지 않습니다. 안드로이드 앱은 인터넷 권한을 요청하지 않습니다.

  • 인터넷 주소(GitHub Pages)로 앱을 열 때는 앱 파일만 받습니다. 이때 GitHub가 보안을 위해 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.
  • 근거 자료·레시피·판매처 링크를 누르면 해당 사이트로 이동합니다. 그 사이트의 방침은 각 사이트를 확인해 주십시오.

3. 카메라(바코드 읽기)

'바코드로 찾기'에서 카메라로 읽기를 누를 때만 카메라 권한을 묻습니다. 카메라 화면은 기기 안에서 바코드 숫자를 읽는 데만 쓰고, 사진·영상을 저장하거나 보내지 않습니다. 처음 보는 바코드를 음식과 연결하면 그 바코드 숫자와 음식 이름만 기기 안에 남습니다(백업에 포함, '연결 지우기'로 삭제).

4. 백업 파일·공유·자동 백업 폴더

  • '백업 파일 저장', '백업 내용 복사', '백업 파일 보내기(공유)', 자동 백업 폴더로 만든 백업에는 건강 정보가 들어 있습니다. 이 파일은 사용자가 직접 보관하고 전달합니다.
  • 공유를 누르면 사용자가 고른 앱(메일·메신저·파일 앱 등)으로 파일이 넘어가며, 그 뒤에는 그 앱의 방침을 따릅니다.
  • 자동 백업 폴더(PC): 기록이 바뀔 때 고른 폴더에 날짜별 백업 파일을 쓰고 30일이 지난 파일은 지웁니다. OneDrive·구글 드라이브·iCloud 같은 동기화 폴더를 고르면 그 서비스에도 올라가므로 백업 암호화를 켜 두십시오.
  • 백업 암호화(선택): 켜면 위 백업 내용을 비밀번호로 암호화합니다(PBKDF2-SHA256 31만 회 → AES-GCM 256). 비밀번호를 잊으면 그 백업은 누구도 되살릴 수 없습니다. 기기 안 자동 보관본·CSV·진료용 PDF는 암호화하지 않습니다.
  • 메신저·이메일로 보낼 때는 받는 사람을 확인하고, 다른 사람이 쓰는 기기에 남기지 마십시오.

5. 진료용 PDF와 CSV

진료용 PDF와 CSV(증상 기록·먹은 음식)는 기기 안에서 만들어 사용자가 고른 곳에 저장합니다. 증상·음식 평가·복용 약·의료진 지시·검사 수치·약 메모·진료 때 물어볼 것이 들어갈 수 있습니다.

6. 알림

'기록 알림'을 켜면 마지막 증상 기록 날짜만 기기 안에 남겨, 3일 넘게 기록이 없을 때 기기 안에서 알림을 만듭니다(안드로이드 앱: 기기 알람, 설치한 웹앱: 브라우저 알림). 이 날짜도 서버로 보내지 않습니다. 캘린더 알림은 기기에 내려받는 일정 파일(.ics)이며 사용자가 캘린더 앱에 직접 넣습니다. 알림은 앱 설정에서 언제든 끌 수 있습니다.

7. 보관 기간과 삭제

  • 기록은 사용자가 지울 때까지 기기에 남습니다. 자동 보관본은 최근 7일치만 남깁니다.
  • 전체 초기화('내 정보 > 데이터 백업 > 전체 초기화'): 기록 본체와 함께 기기 안 자동 보관본·불러오기 전 기록·손상 사본·암호화 열쇠·자동 백업 폴더 연결, 안드로이드 앱의 옮겨 둔 예전 기록까지 지웁니다. 확인 창의 스위치를 끄면 자동 보관본(최근 7일)은 남겨 되살릴 수 있습니다.
  • 이미 기기 밖으로 내보낸 파일(내려받은 백업 파일, PC 자동 백업 폴더의 파일, 공유한 파일, PDF·CSV)은 앱이 지울 수 없으니 직접 지워 주십시오.
  • 그 밖의 방법: 브라우저의 사이트 데이터 삭제, 안드로이드 앱 삭제

8. 이용 대상

궤양성 대장염이 있는 19세 이상 성인을 위한 참고용 기록 앱입니다. UC TABLE은 의료기기가 아니며 진단·치료를 하지 않습니다. 식사 조절은 주치의·영양사와 상의하십시오.

9. 스토어 데이터 보안 응답(요약)

수집하는 데이터없음(기기 안에서만 처리하는 데이터는 수집에 해당하지 않음)
제3자 공유없음(사용자가 직접 공유하는 파일은 사용자가 고른 앱으로 전달)
권한카메라: 바코드를 기기 안에서 읽을 때만, 저장·전송 없음. 알림: 기록 알림을 켤 때만. 인터넷 권한 없음(안드로이드)
전송 중 암호화해당 없음(전송하지 않음). 웹 앱 파일은 HTTPS로 제공
데이터 삭제 요청사용자가 앱에서 직접 삭제(위 7항)
