UC TABLE 개인정보 처리방침

시행일 2026-10-14 · 앱 버전 1.9.0부터 적용

한 줄 요약: UC TABLE은 개인정보를 수집하지 않습니다. 입력한 기록은 사용자의 기기 안에만 저장되고, 개발자를 포함해 누구에게도 전송되지 않습니다.

1. 처리하는 정보

앱에 입력하는 증상(배변 횟수·혈변·복통 등), 식사, 몸무게, 키·나이·성별, 알레르기, 복용 약, 의료진 지시, 메모는 사용자의 기기에만 저장됩니다.

  • 웹·설치형(PWA): 브라우저 저장 공간(localStorage)
  • 안드로이드 앱(APK): 앱 내부 저장 공간

앱에는 서버·회원 가입·로그인이 없습니다. 개발자는 이 기록을 볼 수도, 받을 수도 없습니다.

2. 외부로 보내는 정보

없습니다. 분석 도구, 광고, 추적 코드, 사용 통계를 쓰지 않습니다. 안드로이드 앱은 인터넷 권한도 요청하지 않습니다.

  • 인터넷 주소(GitHub Pages)로 앱을 열 때는 앱 파일만 받습니다. 이때 GitHub가 보안을 위해 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.
  • 근거 자료·레시피 링크를 누르면 해당 사이트로 이동합니다. 그 사이트의 방침은 각 사이트를 확인해 주십시오.

3. 백업 파일과 진료용 PDF

'데이터 백업'으로 저장한 파일과 진료용 PDF에는 건강 정보가 들어 있습니다. 이 파일은 사용자가 직접 보관하고 전달합니다. 메신저·이메일로 보낼 때는 받는 사람을 확인하고, 다른 사람이 쓰는 기기에 남기지 마십시오.

4. 알림

'기록 알림'을 켜면, 마지막 증상 기록 날짜만 기기 안에 남겨 3일 넘게 기록이 없을 때 기기 안에서 알림을 만듭니다. 이 날짜도 서버로 보내지 않습니다. 알림은 앱 설정에서 언제든 끌 수 있습니다.

5. 보관 기간과 삭제

  • 기록은 사용자가 지울 때까지 기기에 남습니다.
  • 모두 지우기: 앱의 '내 정보 > 데이터 백업 > 전체 초기화', 또는 브라우저의 사이트 데이터 삭제, 또는 안드로이드 앱 삭제

6. 이용 대상

궤양성 대장염이 있는 19세 이상 성인을 위한 참고용 기록 앱입니다. UC TABLE은 의료기기가 아니며 진단·치료를 하지 않습니다. 식사 조절은 주치의·영양사와 상의하십시오.

7. 스토어 데이터 보안 응답(요약)

수집하는 데이터없음(기기 안에서만 처리하는 데이터는 수집에 해당하지 않음)
제3자 공유없음
전송 중 암호화해당 없음(전송하지 않음). 앱 파일은 HTTPS로 제공
데이터 삭제 요청사용자가 앱에서 직접 삭제(위 5항)
