# 출시 준비(v1.9.0)

이 문서는 GitHub Pages 배포, 직접 받는 APK, Google Play·App Store 등록에 필요한 것을 한곳에 모은 것입니다.
정책 문구는 2026-10-14에 각 공식 도움말에서 확인했습니다(아래 출처). 정책은 바뀌므로 등록 직전에 다시 확인하십시오.

## 1. 배포 주소(GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 한 번 바꿉니다.
2. main에 올리면 `.github/workflows/pages.yml`이 `public/`(PWA, 처리방침, 접근성 안내)을 배포합니다.
3. 주소
   - 앱: https://park11234.github.io/uc-table/
   - 개인정보처리방침: https://park11234.github.io/uc-table/privacy.html (문의 smpsh0125@gmail.com)
   - 접근성 안내: https://park11234.github.io/uc-table/accessibility.html

## 2. 직접 받는 APK(지금 방식)

- `uc-table.apk`는 앱 파일(오프라인 단일 파일)을 APK 안에 넣은 WebView 앱입니다. **인터넷 권한이 없고**, v2·v3 서명입니다.
- 직접 받은 APK를 설치할 때 나오는 ‘출처를 알 수 없는 앱’ 확인은 안드로이드가 강제하는 단계라 파일 쪽에서 없앨 수 없습니다. 경고 없이 설치하려면 Play 스토어 등록이 필요합니다.
- 안드로이드 개발자 확인(developer verification)은 2026-09-30부터 브라질·인도네시아·싱가포르·태국에서 시작했고 전 세계로 넓힐 예정입니다. 넓어지면 등록하지 않은 개발자의 APK는 설치 절차가 길어지므로(개발자 모드, 하루 대기 등) 그 전에 패키지 이름(`io.github.park11234.uctable`)을 등록하는 것을 권합니다.
- **서명 키(.jks)와 비밀번호는 저장소에 올리지 않습니다.** 키를 잃으면 같은 이름으로 업데이트를 낼 수 없으니 따로 보관하십시오.

## 4. App Store

- 의료·건강처럼 규제가 많은 분야는 개인 개발자가 아니라 서비스를 제공하는 법인이 제출하라는 심사 지침(5.1.1(ix))이 있어 **개인 계정으로는 거절될 수 있습니다.**
- 건강 정보의 근거와 방법을 밝히고 의사와 상담하도록 알려야 합니다(1.4.1). 앱은 근거 번호와 원문 인용, ‘의료기기가 아님’ 문구를 갖고 있습니다.
- 웹사이트를 다시 포장한 수준이면 거절될 수 있습니다(4.2). 오프라인 동작·기록·PDF 같은 앱 기능을 설명에 드러냅니다.
- 앱 개인정보 항목은 ‘데이터를 수집하지 않음’.

## 5. 스토어 문안(초안)

**앱 이름**: UC TABLE – 궤양성 대장염 식단 도우미

**짧은 설명(80자 안)**: 궤양성 대장염 식단 도우미. 증상 기록으로 식사 단계를 정하고 음식마다 판정과 근거를 보여 줍니다.

**자세한 설명**

> 궤양성 대장염 환자가 “오늘 이거 먹어도 되나?”를 근거와 함께 확인하도록 돕는 식단 관리 도우미입니다.
>
> • 증상 기록(4쪽, ‘평소와 같음’ 한 번 누르기)으로 지금의 식사 단계(저잔사식·이행식·지중해식)를 고릅니다.
> • 음식 1,750종(마트·편의점 시판 제품 1,076종 포함)을 좋음·주의·보류·피하기·절대 금지로 판정하고, 판정마다 진료지침·병원 식이 안내·논문의 근거 번호를 붙였습니다. 아질산염(발색제)을 넣은 가공육은 ‘절대 금지’입니다.
> • 시판 제품은 판매처 상품정보의 영양정보·원재료명·알레르기 표시를 그대로 보여 주고, 확인한 곳과 날짜를 밝힙니다.
> • 단계·알레르기·의료진 지시에 맞춘 7일 예시 식단, 장보기 목록, 먹은 음식·물 기록과 영양 합계.
> • 먹은 날과 먹지 않은 날의 증상 점수를 비교한 ‘의심 후보’(원인이라는 뜻은 아닙니다).
> • 진료 때 보여 줄 PDF(글자 PDF·그림 PDF)와 ‘진료 때 물어볼 것’.
> • 인터넷 없이 동작하고, 기록은 이 기기에만 저장합니다. 계정·서버·광고·분석 도구가 없습니다.
>
> 이 앱은 의료기기가 아니며 진단이나 치료를 대신하지 않습니다. 판정은 공개된 지침의 일반 권고를 옮긴 참고 정보이므로, 식사와 치료는 반드시 주치의·영양사와 상의하십시오. 시판 제품 정보는 확인한 날의 판매처 표시이며 포장이 바뀌었을 수 있습니다.
