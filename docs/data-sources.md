# 데이터 출처와 이용 조건

## 1. 영양성분 — 식품의약품안전처 통합식품영양성분DB

음식 439종의 열량·단백질·지방·탄수화물·식이섬유·칼슘·철·칼륨 값은
식품의약품안전처 **통합식품영양성분DB**(원재료성 식품, 음식, 가공식품, 품목제조보고)의 대표값입니다.

- 받는 곳: 공공데이터포털(data.go.kr) 또는 식품안전나라(foodsafetykorea.go.kr)에서 CSV로 내려받습니다.
- 이 저장소에는 **원본 CSV를 포함하지 않습니다.** 재생성하려면 내려받은 파일을 `data/mfds/`에
  `raw.csv`(원재료성), `dish.csv`(음식), `proc.csv`(가공식품), `prep.csv`(품목제조보고)로 두고
  `python3 src/data/generate_dataset.py`를 실행하세요.
- 앱에는 선택한 행의 값·식품코드·식품명·기준량만 들어 있고, 각 음식 상세 화면에 출처와 코드가 그대로 표시됩니다.
- 이용 조건은 내려받는 시점의 공공데이터 이용 허락 범위(공공누리 등)를 따르며, 출처 표시를 유지해야 합니다.

### 값을 고른 규칙

- 같은 이름의 행이 여러 개일 때는 분석값이 있는 계열을 우선하고(D1 → D3 → D5 → D4 → D6 → D7),
  프랜차이즈 제공값 계열(D2)은 결측이 많아 제외했습니다.
- 위 규칙으로 뽑은 행의 식이섬유가 같은 음식의 다른 계열보다 비정상적으로 크면(예: 잡곡밥 6.1 g)
  코드로 직접 지정해 바로잡았습니다. 지정 목록은 `src/data/generate_dataset.py`의 `EXC`에 있습니다.
- 고형 음식인데 기준량이 `100ml`로 적힌 행은 표기만 `100g`으로 바꿉니다(값은 그대로).

## 2. 판정 규칙 — 진료지침·병원 식이 안내·논문

단계별 허용/제한, 섬유·지방·염분 기준, 조리법 안내는 아래 자료에서 가져왔습니다.
전체 목록과 서지 정보는 [evidence.md](evidence.md)에 있고, 앱 화면의 위첨자 번호가 그 목록의 번호입니다.

- 국제 지침: ESPEN(2023), AGA(2024), IOIBD(2020), ECCO(2017)
- 국내 자료: 대한장연구학회 환자 안내, 가천대 길병원 저잔사식 안내
- FODMAP: Monash University 공개 식품표·안내문
- 활동도 점수: SCCAI(Walmsley 1998, Jowett 2003)
- 영양 기준: 2025 한국인 영양소 섭취기준(KDRI)

인용은 공개된 지침·논문의 **내용을 요약해 코드 규칙으로 옮긴 것**이며, 원문을 복제해 배포하지 않습니다.

PDF 내보내기에 쓰는 두 라이브러리를 `vendor/`에 원본 그대로 두고, 오프라인 빌드에 인라인합니다.

| 라이브러리 | 버전 | 라이선스 |
|---|---|---|
| html2canvas | 1.4.1 | MIT (`vendor/html2canvas.LICENSE`) |
| jsPDF | 2.5.1 | MIT (`vendor/jspdf.LICENSE`) |

글꼴은 내려받지 않고 기기에 있는 글꼴을 씁니다(오프라인 빌드는 외부 요청이 0건입니다).
